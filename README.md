# 蜀韵·成都 · 成都文化旅游宣传网站

一个以「现代简约 + 金色主题」为视觉方向的成都文化旅游宣传网站，共 5 个页面，使用原生 HTML5、CSS3 与 JavaScript 编写，无任何第三方依赖，可直接在 Visual Studio Code 中打开和预览。

## 页面一览

| 文件 | 页面 | 主要内容 |
| --- | --- | --- |
| `index.html` | 首页 | 全屏三图轮播、成都城市宣传短片、约 300 字城市介绍、城市数据、三条探索线索、诗句收尾 |
| `food.html` | 美食 | 火锅、串串香、担担面、龙抄手，以及街头小吃与茶馆文化 |
| `sights.html` | 景点 | 宽窄巷子、锦里、大熊猫基地、都江堰、青城山、武侯祠 |
| `culture.html` | 文化 | 川剧变脸、蜀绣、茶馆文化、三国文化，附成都非遗名录 |
| `travel.html` | 攻略 | 出行速览、**交通方式对比表格**、三日行程、实用贴士 |

五个页面共用同一套页头、页脚、导航与设计规范；当前页面会在导航中高亮显示。

## 在 VS Code 中打开

1. 打开 Visual Studio Code。
2. 选择「文件 → 打开文件夹」，打开本目录：

   ```
   D:\插件\input
   ```

3. 推荐安装扩展 **Live Server**（项目已在 `.vscode/extensions.json` 中给出推荐）。
4. 在 `index.html` 上右键，选择 **Open with Live Server**。

也可以不用插件，在终端中执行：

```powershell
cd /d D:\插件\input
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

> 直接双击 `index.html` 也可以浏览大部分内容；使用本地服务器可以获得更稳定的视频与字体加载体验。

## 功能与实现要点

- **全屏 Banner 轮播**：3 张成都主题图片，自动播放、左右切换、指示点、触摸滑动、键盘方向键，鼠标悬停或聚焦时暂停。
- **城市宣传视频**：本地 H.264 MP4，自绘播放控件（播放/暂停、进度、时间、全屏），无第三方播放器。
- **固定页头**：首屏透明，滚动后切换为米白毛玻璃；移动端全屏导航带焦点管理。
- **滚动入场**：IntersectionObserver 实现轻量渐入，支持 `prefers-reduced-motion`。
- **响应式布局**：覆盖桌面、平板与手机；交通表格在手机端自动压缩为三列可读布局。
- **结构与样式分离**：HTML 只负责结构，CSS 统一放在 `css/style.css`，交互统一放在 `js/main.js`。
- **中文注释**：HTML 区块、CSS 分区、JavaScript 功能模块均附中文说明。

## 关于交通方式对比表格

`travel.html` 中间位置按要求放置三列表格：**交通方式 / 耗时 / 费用**。其中：

- 地铁：覆盖全城 / ¥3-12
- 出租车：视距离 / ¥15-60
- 景区直通车：1-1.5h / ¥25-35
- 共享单车：15-40 分钟 / ¥1.5-3

> 原始需求截图在「共享单车」一行处被截断，表中共享单车数据按短途接驳场景补齐，可直接在 `travel.html` 中修改。所有价格为日常参考区间，实际以出行当天为准。
